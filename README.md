# Vox

Локальная диктовка для macOS на Apple Silicon. Нажимаете правую `Command` —
идёт запись, нажимаете второй раз — распознанный текст вставляется в активное
поле ввода. Речь не покидает машину.

Состояние: bootstrap. Приложение ещё не собрано.

## Требования

- macOS 14 или новее;
- Apple Silicon;
- Swift 6.

## Сборка

```
swift build -c release
```

## Служебные проверки

```
.build/debug/Vox --self-test
```

## Разделы, которые появятся по мере готовности

- получение и проверка модели;
- сборка `.app` и установка в `/Applications`;
- выдача разрешений macOS: Microphone, Accessibility, Input Monitoring;
- работа правой `Command`;
- запуск regression;
- удаление;
- приватность;
- ограничения.

## Приватность в двух словах

Приложению нужны широкие разрешения macOS: глобальный перехват событий
клавиатуры для хоткея и Accessibility для вставки текста. Взамен оно не имеет
разрешённой исходящей сети, не пишет аудио и расшифровки на диск и не ведёт
историю.
