## Задача

**1. `scripts/fetch-model.sh` — контролируемая сборочная загрузка модели.**

Качает из `FluidInference/parakeet-tdt-0.6b-v3-coreml` ревизии
`7dd20fe6b1797d35f5e3307e8b1732d9a178edfe` ровно пять артефактов и ничего сверх:
`Preprocessor.mlmodelc`, `Encoder.mlmodelc`, `Decoder.mlmodelc`,
`JointDecisionv3.mlmodelc`, `parakeet_vocab.json`. Это около 483 МБ.

Скрипт обязан:
- работать по закреплённой ревизии, не по ветке и не по `main`;
- иметь в репозитории список ожидаемых файлов с SHA-256 — `scripts/model-files.txt`.
  Сгенерируй его один раз с фактической ревизии и закоммить: без него проверка
  целостности ничего не проверяет;
- считать SHA-256 каждого скачанного файла и сверять со списком;
- отвергать неожиданные файлы и symlink, а не молча их принимать;
- писать `vox-model-manifest.json` в каталог модели по типу `ModelManifest` из VoxCore;
- складывать результат в `models/parakeet-tdt-0.6b-v3-coreml/` — этот путь в `.gitignore`;
- падать с понятным сообщением и ненулевым кодом при любом расхождении;
- различать три исхода проверки: найдено, чисто, инструмент сломался. Exit code
  инструмента, отличный от ожидаемых, — провал шага, а не «совпадений нет».

**2. Модуль `VoxSTT`.**

- Определение каталога модели детерминированное, без настроек: запущены из
  `.app` — берём `Contents/Resources/Models/...`; иначе `models/...` относительно
  текущего каталога. Никаких переменных окружения «на всякий случай».
- Проверка целостности до загрузки: манифест читается, каждый файл сверяется по
  размеру и SHA-256, лишние файлы и symlink отвергаются. Ошибки — `VoxError.modelMissing`
  и `VoxError.modelCorrupted`.
- `Transcriber` — actor, реализует `Transcribing`. Загружает модель через
  `AsrModels.load(from:)` и НИКОГДА не вызывает `AsrModels.download`, `downloadAndLoad`
  или `loadWithAutoRecovery`. Приложение не чинит и не докачивает модель.
- Проверь эмпирически, какой каталог надо передавать в `AsrModels.load(from:)`:
  `AsrModels.repoPath` берёт родителя переданного пути и приписывает `parakeet-tdt-0.6b-v3-coreml`.
  Разойдётся с разведкой — поправь `Pins.modelBundleSubpath`… нет, `Pins` заморожен:
  сообщи мне точное расхождение в отчёте, а у себя используй рабочий путь.
- `STTEntry.transcribeFile(_:)`: читает аудиофайл, приводит к mono 16 kHz Float32
  через AVFoundation, распознаёт, возвращает сырой текст. Временных файлов не создаёт.
- `STTSelfTest.cases()` наполни минимум тремя случаями: манифест валиден;
  подделанный байт в файле модели ловится как `modelCorrupted` (делай на временной копии,
  не порти рабочий каталог); модель грузится без сети.
