Что строим
`Vox.app` представляет собой локальную диктовку для macOS на Apple Silicon.
Пользовательский путь:

1. Пользователь один раз нажимает правую `Command`.
2. Начинается запись с микрофона.
3. Сверху экрана появляется индикатор записи.
4. Второе нажатие правой `Command` останавливает запись.
5. Приложение локально распознаёт речь.
6. Текст проходит консервативную локальную обработку.
7. Результат вставляется в активное поле ввода.
8. Предыдущее содержимое буфера обмена восстанавливается, если пользователь не изменил его во время операции.

Левая `Command` должна работать как обычно.

Рабочие субагенты, которые пишут проект, работают на сильной модели. Haiku разрешена только как испытуемая модель после завершения приложения.
Поведение приложения
Приложение живёт в menu bar и запускается вручную.
В menu bar нужны:

* текущий статус;

Состояния:

Во время `recording` новая запись не запускается. Во время `transcribing` повторный hotkey игнорируется. После ошибки приложение возвращается в рабочее состояние, если повторная попытка безопасна.

Хоткей
Глобальный hotkey работает через `CGEvent.tapCreate`.
Правая `Command`:

* virtual key code `54`;
* отслеживается через `flagsChanged`;
* первое событие нажатия переключает запись;
* отпускание не переключает состояние;
* повторное событие без смены состояния игнорируется;
* событие правой `Command` не должно превращаться в обычный модификатор для активного приложения;
* остальные клавиши и левая `Command` проходят без изменений.

Обработай отключение event tap системой по timeout или user input: включи tap повторно.
Добавь небольшой чистый state transition и self-test для:

* первого нажатия;
* повторного события;
* отпускания;
* левой `Command`;
* нажатия во время распознавания.

Запись
Используй `AVAudioEngine`.
Контракт записи:

```
microphone -> mono 16 kHz Float32 samples in memory
```

Аудио хранится только в памяти текущего процесса. Не создавай временные аудиофайлы, кэш диктовок или журнал восстановления.

На остановке:

Слишком короткую запись отклоняй понятным сообщением.
Одновременно разрешена только одна операция распознавания. Используй actor, а не собственную систему блокировок вокруг модели.
Индикатор
Во время записи показывай небольшую тёмную капсулу по центру в верхней части экрана.
Внутри:

* восемь красных вертикальных полос;
* высота полос реагирует на RMS-громкость;
* индикатор обновляется примерно 30 раз в секунду;
* тихий сигнал не должен создавать резкие скачки;
* окно не получает фокус;
* не принимает клики;
* видно на всех Spaces и поверх fullscreen-приложений.

После остановки записи индикатор записи исчезает сразу. На время распознавания покажи простое состояние обработки без второй сложной анимации.
Добавь self-test для функции, которая переводит уровень звука в высоты полос.
Распознавание
Используй FluidAudio и локальную модель Parakeet TDT 0.6B v3.
На старте процесса:

1. Активируй запрет исходящих сетевых соединений.
2. Установи offline mode FluidAudio.
3. Только после этого создавай app delegate, загружай модель или обращайся к любому API FluidAudio.

Модель должна лежать внутри:

```
Vox.app/Contents/Resources/Models/
```

Build script:

* скачивает модель только во время контролируемой сборки;
* использует закреплённую ревизию;
* проверяет SHA-256 каждого ожидаемого файла;

* не пытается удалить, починить или скачать модель;
