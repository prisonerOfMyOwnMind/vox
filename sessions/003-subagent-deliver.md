## Задача

**1. Запрет исходящей сети на уровне процесса.**

`Bootstrap.activateNetworkLockdown()` вызывается первой строкой процесса, до app
delegate, до загрузки модели, до любого обращения к FluidAudio. Реализуй запрет
исходящих соединений для собственного процесса; ожидаемый механизм — seatbelt
профиль через `sandbox_init`, API устаревший, но рабочий. Не удалось применить —
бросай `VoxError.networkLockdownFailed`, процесс завершается с ошибкой.

Убери случай `.notImplemented` из `LockdownStatus`: он существует только как
заглушка bootstrap.

ВАЖНО И ЧЕСТНО: запрет вполне может конфликтовать с Accessibility, Input
Monitoring или загрузкой системных framework. Конфликт есть — НЕ ослабляй запрет
молча и не подменяй проверку приложения проверкой отдельного helper. Зафиксируй
точный симптом, точный вывод и верни это мне как отрицательный результат. Такой
результат ценнее подогнанного зелёного.

**2. Разрешения.** Проверяй и объясняй по отдельности: Microphone, Accessibility,
Input Monitoring. Пользователь должен понимать, чего именно не хватает и что
нажать. В menu bar — команда повторной проверки.

**3. Хоткей.** `CGEvent.tapCreate`, правая `Command`, virtual key code `54`,
отслеживание через `flagsChanged`.
- первое событие нажатия переключает запись;
- отпускание состояние не меняет;
- повторное событие без смены состояния игнорируется;
- событие правой `Command` не должно доезжать до активного приложения обычным
  модификатором;
- левая `Command` и все прочие клавиши проходят без изменений;
- система отключает tap по timeout или user input — включай обратно.

Логика перехода состояний — отдельный ЧИСТЫЙ тип без AppKit и без глобального
состояния, чтобы её можно было прогнать в self-test. Пять случаев обязательны:
первое нажатие, повторное событие, отпускание, левая `Command`, нажатие во время
распознавания.

**4. Запись.** `AVAudioEngine`, контракт `microphone -> mono 16 kHz Float32 в памяти`.
Старт: очистить старый буфер, проверить формат входа, поставить tap, запустить
engine, показать индикатор. Остановка: запретить добавление samples, снять tap,
остановить engine, отдать массив одному worker распознавания, очистить samples и
после успеха, и после ошибки. Слишком короткая запись отклоняется понятным
сообщением. Временные аудиофайлы, кэш диктовок и журнал восстановления запрещены.

**5. Индикатор.** Тёмная капсула по центру сверху экрана, восемь красных
вертикальных полос, высота реагирует на RMS-громкость, обновление около 30 раз в
секунду. Тихий сигнал не должен давать резкие скачки — нужно сглаживание. Окно
не получает фокус, не принимает клики, видно на всех Spaces и поверх
fullscreen-приложений. После остановки записи индикатор исчезает сразу; на время
распознавания — простое состояние обработки без второй сложной анимации.

Функция «уровень звука → высоты полос» — чистая, с self-test.

**6. Menu bar.** Текущий статус, команда начать или остановить диктовку, команда
повторной проверки разрешений, короткая подсказка про правую `Command`, `Quit`.
Состояния ровно из `AppState`. Во время `recording` новая запись не стартует, во
время `transcribing` повторный хоткей игнорируется. После ошибки возврат в
рабочее состояние, если повторная попытка безопасна.

Не добавляй: историю расшифровок, аккаунты, телеметрию, обновлятор, автозапуск,
LaunchAgent, login item, фоновый helper, настройки ради настроек, полноценное окно.

**7. Буфер обмена.** Сохранить ВСЕ типы и данные текущих items; положить результат;
отправить `Cmd+V` через `CGEvent`; через короткую задержку проверить, что в
буфере всё ещё наш временный текст; восстановить прежнее содержимое ТОЛЬКО если
пользователь его сам не менял. Вставить не удалось — ошибку не прятать.
Содержимое расшифровки в обычный лог не писать.

**8. `scripts/build-app.sh`.** Собирает `Vox.app`: release-сборка, `Info.plist`
с `LSUIElement` и описанием доступа к микрофону, копирование проверенной модели в
`Contents/Resources/Models/`, повторная проверка модели после копирования,
подпись и проверка подписи.
Скрипт получения модели `scripts/fetch-model.sh` делает параллельная ветка `stt`,
в твоём worktree его нет. Вызывай его, если он есть, и падай с внятным
сообщением, если нет. Сквозная сборка bundle проверяется после слияния — так и
напиши в отчёте.

**9. Тесты** в `tests/VoxTests/App*.swift`, фреймворк `Testing`.

## Приватность

Запрещены `URLSession`, Network.framework, сокеты, WebKit-запросы, subprocess для
сетевого клиента, updater, remote config, загрузка модели в runtime, автоматически
открываемые ссылки, отправка crash reports. Логи не содержат аудио, расшифровок,
буфера обмена, содержимого активного приложения и нажатых клавиш. Event tap читает
только тип события, key code и modifier flags — ничего больше.
